# 51. N-Queens

## 一句话题意

在 `n x n` 棋盘上放 `n` 个皇后，使它们互不攻击，返回所有不同的摆放方案。

## 核心思路

逐行回溯：

1. 每行恰好放一个皇后，因此行冲突天然不存在，只需处理列、主对角线、副对角线。
2. 主对角线满足 `row - col` 为常数，副对角线满足 `row + col` 为常数；用三个 `Set` 记录已被占用的列和两类对角线，冲突判断是 `O(1)`。
3. 在第 `row` 行枚举所有列，合法则落子、递归到下一行，返回后撤销（回溯）。
4. 递归到 `row === n` 时，用 `queens` 数组构造 `"."` + `"Q"` + `"."` 的棋盘字符串，加入答案。

## 复杂度

- 时间：最坏 `O(n!)`，但列与两条对角线的剪枝会砍掉绝大部分分支；`n <= 9` 时实际搜索量很小（`n = 9` 只有 352 个解）。
- 空间：`O(n)` 递归深度加三个集合，另有 `O(n^2)` 的输出开销。

## 边界与易错点

- `n = 1` 返回 `[["Q"]]`；`n = 2`、`n = 3` 无解，必须返回空数组而不是 `null`。
- 输出顺序任意，但同一方案不能重复；测试用排序后的字符串集合比较。
- 回溯时三个 `Set` 必须与 `queens` 同步删除，否则会错误剪枝。
- 生成每一行字符串时小心下标：`n - col - 1` 个点，`n = 1` 时两侧点串都是空串。
- 本题约束到 `n = 9`，递归深度最多 9 层，不存在爆栈风险。
