# 5. Longest Palindromic Substring

## 一句话题意

给定字符串 `s`，返回其中最长的回文子串（长度相同时返回任意一个即可）。

## 核心思路

使用 Manacher 算法，把时间复杂度降到线性：

1. 在字符之间插入 `#`，并在首尾加上 `^`、`$` 两个哨兵，例如 `abba` 变成 `^#a#b#b#a#$`。这样奇数长度和偶数长度的回文被统一成“以某个位置为中心”的形式。
2. `p[i]` 表示以 `t[i]` 为中心的回文半径，它也恰好等于原串中该回文的长度。
3. 维护当前能到达最右端的回文中心 `center` 及其右边界 `right`。当 `i < right` 时，`i` 关于 `center` 的对称点 `mirror` 已经算过，可以令 `p[i] = min(right - i, p[mirror])` 作为下界，再从这个下界继续向两边扩展。
4. `right` 只会单调右移，因此总扩展次数是 `O(n)`；每次更新最大半径，最后按 `start = (bestCenter - bestRadius) / 2` 截取原串。

## 复杂度

- 时间：`O(n)`（Manacher）。
- 空间：`O(n)`，用于变换后的字符串和半径数组。

## 边界与易错点

- 空串不在约束内，但代码对 `length <= 1` 直接返回原串，保证鲁棒。
- 下标换算：`t` 中半径 `r` 对应原串长度 `r`，起点是 `(center - r) / 2` 向下取整，不要四舍五入。
- `^`、`$` 必须是字符串中不会出现的字符（题目只说数字和英文字母），否则会破坏边界判断。
- 题目允许多个正确答案（例如 `babad` 的 `bab` 和 `aba`），测试因此校验“是回文 + 是子串 + 长度正确”，而不是死盯某一个字符串。
- 常见替代解法是中心扩展 `O(n^2)`、动态规划 `O(n^2)`；在 `n <= 1000` 时也能通过，但这里采用了最优的线性解法。
