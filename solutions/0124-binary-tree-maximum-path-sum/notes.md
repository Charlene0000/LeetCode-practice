# 124. Binary Tree Maximum Path Sum

## 一句话题意

在二叉树中找一条节点不重复的路径，使路径上节点值之和最大；路径可以不经过根，但至少包含一个节点。

## 核心思路

树形 DP（后序遍历）：

对每个节点 `node` 计算 `gain(node)`——从 `node` 出发、最多向一侧子树延伸的“向下最大路径和”：

```
gain(node) = node.val + max(0, gain(left), gain(right))
```

其中 `max(0, ...)` 表示负收益的子树直接丢弃。

同时，以 `node` 为最高点（拐点）的路径可以把左右两侧的向下路径都接上：

```
candidate = node.val + max(0, gain(left)) + max(0, gain(right))
```

全局答案取所有 `candidate` 的最大值。实现上用显式栈先得到前序节点序列，再逆序计算，等价于后序遍历；`gain` 存放在 `Map` 中。这样即使树退化成 3 万节点的链，也不会因为递归过深而爆栈。

## 复杂度

- 时间：`O(n)`，每个节点只被访问常数次。
- 空间：`O(n)`，节点顺序数组与 `gain` 映射；不使用递归栈。

## 边界与易错点

- 全负数时不能返回 0：路径必须非空，答案是最大的单个节点值（例如 `[-3] -> -3`）。
- 更新全局答案时左右子树收益要截断为 `0`，但向上返回时只能选**一侧**，不能把两条分支都带上去。
- 空树不在约束内；防御性地返回 `0`。
- 节点值范围 `[-1000, 1000]`，3 万节点链最大和约 `3 * 10^7`，普通 Number 足够。
- 递归写法更短，但深度可能达到 3 万；这里故意用迭代 + 逆序处理来规避 `RangeError: Maximum call stack size exceeded`。
