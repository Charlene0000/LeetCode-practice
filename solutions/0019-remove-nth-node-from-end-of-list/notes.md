# 19. Remove Nth Node From End of List

## 一句话题意

删除单链表倒数第 `n` 个节点，返回新的头节点，要求只遍历一遍。

## 核心思路

使用哑节点（dummy）加双指针：

1. `dummy.next = head`，把“删除头节点”变成和删除中间节点完全一样的操作。
2. `fast` 先从 `dummy` 走 `n + 1` 步，`slow` 停在 `dummy`。
3. 然后 `fast`、`slow` 同步前进，直到 `fast` 走到 `null`。此时 `slow` 恰好指向待删节点的前驱。
4. 执行 `slow.next = slow.next.next`，返回 `dummy.next`。

## 复杂度

- 时间：`O(L)`，`L` 为链表长度，只遍历一遍。
- 空间：`O(1)`，只用了两个指针和哑节点。

## 边界与易错点

- `n == 1` 删除尾节点；`n == L` 删除头节点，都必须正确处理，哑节点正是为此存在。
- 只有 1 个节点且 `n == 1` 时，结果应为 `null`，不能返回被删除的节点。
- `fast` 要走 `n + 1` 步而不是 `n` 步，否则 `slow` 会停在待删节点本身，无法改链。
- 题目保证 `1 <= n <= L`，不需要处理越界；若自行扩展接口，建议先校验。
- 不要先求长度再正向删除：虽然也是 `O(L)`，但需要两趟遍历，不符合 follow-up 的“一趟”要求。
- 测试里把链表转成数组再断言，方便比较且避免打印链表对象。
